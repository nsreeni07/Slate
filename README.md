# Slate
A custom mechanical keyboard designed from scratch in CAD, it has a 65%-style layout with hot-swappable key switches, a Raspberry Pi Pico as the controller, screw-in stabilizers. I built this keyboard because for a long time I have always wanted my own keyboard and the keyboard on my laptop isnt the best. I also made a custom wrist rest to make typing easier for long durations.
